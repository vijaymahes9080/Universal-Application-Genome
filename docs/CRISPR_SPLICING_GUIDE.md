# ✂️ CRISPR Autonomous Feature Splicer Guide

The CRISPR Splicing module allows targeted gene extraction and AST code transformation.

![CRISPR Code Splicer Interface](images/crispr_editor_mockup.png)

## 🛠️ Step-by-Step Splicing Workflow

1. **Navigate to `/crispr`**: Access the live workspace.
2. **Select Donor Gene**: Choose from Stripe Checkout, Zero-Trust Auth, Real-Time WebSockets, or RAG Vector Indexer.
3. **Choose Host Application**: Target an ingested codebase.
4. **Execute Splicer**: Generates AST patches, merges routes, resolves dependencies, and updates the Software Genome Graph.
